# Pasos para Colaborar

### Creación de una nueva rama local

1.  Cambiar a la rama principal

```bash
git checkout main
```

2.  Actualizar el repositorio local
```bash
git pull origin main
```

3. Crear y cambiar a la nueva rama localmente
```bash
git checkout -b meliza-daza
```

4. Subir la rama local al repositoirio remoto por primera vez
```bash
git push -u origin meliza-daza
```
